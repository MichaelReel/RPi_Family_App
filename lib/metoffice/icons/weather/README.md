# MET Weather API icons

This is a set of icons designed to be used with the following MET API products:

- Locationforecast/2.0
- Nowcast/2.0

The weather icons can be found in the `weather` folder.

`spares/` holds extra, currently-unused icon variants (kept on disk for reference; git-ignored).
